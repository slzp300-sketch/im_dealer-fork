# 채널톡 AI 상담 구축 계획안

작성: 2026-08-03 · 근거: Ao{B} 세팅 제안서(2026-07-31) + 기능 가능/불가 구분표, 코드베이스 대조

## 확정된 방향

- **견적서 발송(T0)**: 현재 구현(채널톡 상담창 유도)은 임시방편. **비즈톡으로 확정** — 채널 추가 시 웰컴메시지, 견적서 알림톡 자동발송. 이 방향을 채널톡 세팅 업체에 전달 → 제안서 수정 예정.
- **웹 연동 옵션(S2)**: **보류** — 도입 여부 논의 중.
- **비즈톡 계약 상태**: 진행 중. 서류 준비 → 등기 발송 → 계약 후 비즈톡에서 API 등 개발 자료 제공 예정.

## ① 시스템별 역할 분담

| 시스템 | 담당 | 상태 |
|---|---|---|
| 채널톡 콘솔(S1) — AI 상담, 태그·픽커, 즉시출고 안내 | 세팅 업체(Ao{B}) | 제안서 수정 대기 |
| 비즈톡 — 웰컴메시지, 견적서 알림톡 자동발송 | 우리 개발 | 계약 진행 중 |
| 웹 연동(S2) — 프로필값·이벤트 채널톡 전송 | 우리 개발 | 보류 |
| 자료·인증(S3) — 스프레드시트, 인증, 문구 확정 | 운영 | 회신 대기 |

**이미 구현되어 재개발 불필요**: 채널톡 고객 식별(memberId boot + memberHash, `src/components/layout/ChannelTalk.tsx`), 간편가입 이름·전화 필수 + 마케팅 동의 수집(`src/app/(member)/welcome/WelcomeForm.tsx`), 견적서 이미지 생성·전송 이력(QuoteDelivery), 카카오 채널 추가 상태(User.channelRelation).

## ② 개발 로드맵

### Phase 0 — 지금 가능 (블로커 없음)
1. 비즈톡 연동 설계: API 스펙 검토(자료 수령 후), 발송 파이프라인 설계. 임시방편 자리에 비즈톡 발송을 끼워 넣는 구조로.
2. 알림톡 템플릿 초안: 견적서 보기 버튼 + 채널 추가 유도 한 통 구성. 카카오 검수 영업일 2~3일 소요.

### Phase 1 — 비즈톡 계약 완료 후
1. 비즈톡 발송 모듈: 알림톡 발송 + 결과 콜백 → QuoteDelivery 상태 갱신, 실패 재시도.
2. 견적서 받기 플로우 교체: 임시방편(클립보드 복사→채널 대화창) 제거 → 저장 즉시 알림톡 자동발송. 알림톡은 정보성이라 동의 불요·연락처만 필요(간편가입 전화 필수로 충족).
3. 웰컴메시지: 채널 추가 실시간 감지 방법 확인 필요(channelRelation은 로그인 시점에만 갱신 — 카카오 웹훅 또는 비즈톡 기능 확인).

### Phase 2 — 웹 연동 도입 결정 시
1. 마케팅 수신동의 채널톡 프로필 동기화(철회 포함) — 리마인드 대상의 전제.
2. 커스텀 이벤트 3종: 견적 완료 / 견적서 전송함 / 견적서 열람 — 리마인드 T0 기준 시점.
3. 리드 분류값(고객유형·관심차량) 프로필 전달.

### Phase 3 — 확정값 수령 후 (소규모 웹 수정)
- 제휴 금융사 수 표기 통일(소개 4곳 vs 고지 13개사 불일치), 중개업 등록번호 기재, 운영시간 표기 정합.

## ③ 결정해야 할 사항 (중요도순)

1. **리마인드(T+3d~14d) 발송 파이프** — 웹 연동 결정과 한 세트.
   - 채널톡 브랜드 메시지(제안서안): 템플릿 승인 불요·문구 자유. 단 **웹 연동(S2) 필수**.
   - 비즈톡 직접: 웹 연동 없이 자체 DB로 가능. 단 스케줄러·대상 관리·수신거부 자체 개발 필요. (광고) 표기·08~20시 제한 등 규제는 동일.
2. **웰컴메시지 발송 주체**: 카카오 채널 자동 인사말로 충분한지, 비즈톡 개인화 발송이 필요한지. 후자면 채널 추가 감지 방법을 비즈톡에 확인.
3. **임시방편 유지 기간**: 비즈톡 오픈 전까지 현행 유지 여부, S1 오픈 시 상담 워크플로우와 충돌 없는지 업체와 조율.

## ④ 운영 준비 사항

**세팅 업체 회신 (제안서 11장)**
- 바로 회신 가능: ① 견적서 받기 단계에서 연락처(필수)·마케팅 동의(선택) 수집 중 ② T0 발송은 비즈톡으로 확정
- 결정 후 회신: 웹 연동 도입 여부, 우선 관리 리드 기준
- 자료: 즉시출고 스프레드시트(브랜드·모델·트림·출고 가능 시점·기준일자 + 갱신 주기), 출고 소요 기간 기준, 상담 운영시간(점심·휴일)
- 문구 확정: 제휴 금융사 수, 중개업 등록번호

**비즈톡·카카오**
- 카카오 채널 비즈니스 인증 + 채널톡 비즈니스 인증 상태 확인
- 발신프로필 등록, 알림톡 템플릿 심사 접수
- 발송 비용 확인(알림톡 ~1원, 친구톡 ~15원, 선불/후불)

**팀 내부**
- 팀원(업스트림·배포 오너)에게 비즈톡 연동의 서버 환경변수(API 키)·DB 마이그레이션 가능성 공유.
